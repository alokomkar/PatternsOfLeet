What “runnable” means

Product Record

Source root, entrypoint, run/test commands, local storage, approved proof, visual contract, exclusions, artifact hashes and exact source commit.

Deployment Record

Created only after artifact verification; records offline launch location, acceptance, test status and source commit.

Deterministic core

Business rules live in domain-neutral JavaScript modules tested without relying on decorative UI behavior.

Local persistence

Each application stores working state in device-local browser storage and can be reset without affecting Omkara.
