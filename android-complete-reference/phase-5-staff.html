Phase 5 - 1 to 2 years

Lead architecture across teams.

Goal: stop being measured only by features shipped personally. Staff-level Android work improves how many teams build, test, migrate, observe, and release mobile software.

What to learn

  • Architecture strategy: target state, transition state, migration sequencing, and compatibility policy.
  • Shared platform design: design systems, networking, analytics, experimentation, authentication, and release tooling.
  • Observability: crashes, ANRs, latency, startup, funnels, logs, traces, and actionable dashboards.
  • Technical decision records: context, options, decision, consequences, rollback plan, ownership.
  • Cross-team influence: RFCs, alignment meetings, technical debt negotiation, and phased adoption.
  • Risk management: migration blast radius, dependency health, policy changes, platform deprecations.

Build this project

Write and implement a migration case study: XML to Compose, monolith to modules, RxJava to coroutines, or legacy networking to a typed client. Include code, metrics, and the social rollout plan.

Exit gate
